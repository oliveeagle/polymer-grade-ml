# Контракт экспериментальной записи

Одна запись описывает один материал, состав, режим переработки и результат испытания. Если один образец измерен несколькими методами или при разных условиях, результаты сохраняются отдельными объектами в `measurements`.

## Обязательные поля

| Поле | Смысл |
| --- | --- |
| `record_id` | Неизменяемый идентификатор записи |
| `source.source_id` | Идентификатор статьи, патента или техлиста |
| `material.base_polymer` | Полимер, марка и известные характеристики |
| `formulation.components` | Компоненты, функция, доля и единица |
| `processing` | Метод и заданные параметры процесса |
| `measurements` | Значение, единица, метод и условия измерения |
| `evidence` | Страница/таблица/пример и фрагмент, подтверждающий данные |
| `curation` | Статус проверки и уровень уверенности |

## Правила

- Массовые доли приводятся к `wt_pct`; исходное значение и единица сохраняются отдельно.
- Свойство без метода испытания и условий не используется для обучения до ручной проверки.
- Торговая марка не заменяет химическую идентичность: храните оба значения, если они известны.
- Все температурные значения нормализуются в `degC`, давление — в `MPa`, время — в `s`.
- Каждое значение имеет источник и локатор: страница, таблица, номер примера или диапазон строк OCR.
