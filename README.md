# Polymer Grade ML

Платформа для сбора и нормализации данных из статей, патентов и технических листов, а затем подбора состава и параметров переработки полимерной композиции под заданные свойства.

## Поток данных

`sources → raw → extracted → curated → модели → рекомендации с доказательствами`

Каждая запись в `data/curated` должна сохранять ссылку на первоисточник и точное место в нём (страницу, таблицу или пример).

## Быстрый старт

1. Заполнить справочники в `ontology/`.
2. Помещать неизменённые документы и метаданные в `data/raw/`.
3. Извлекать текст, таблицы и фрагменты доказательств в `data/extracted/`.
4. Проверять и публиковать нормализованные экспериментальные записи в `data/curated/`.

Подробная структура полей приведена в `docs/data-contract.md`.

## Структура

- `sources/` — поисковые запросы, реестры и правила сбора источников.
- `data/` — документы и наборы данных по стадиям обработки.
- `ontology/` — управляемые справочники полимеров, добавок, процессов и свойств.
- `pipelines/` — сбор, извлечение, разбор, нормализация и валидация.
- `models/` — прямые и обратные модели, retrieval и оценка неопределённости.
- `app/` — будущий API и интерфейс для рекомендаций.
- `tests/` — проверки схем, пайплайнов и моделей.
